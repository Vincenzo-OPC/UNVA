# UNVA design system

**Brand:** UNVA. All caps. Short, punchy, deliberately distinctive.  
**Promise:** Before You Hire a VA, Try AI.  
**Product:** An open-source guide and tested setup-pack library, not a robot subscription.

## Default appearance: Ink / Bone / Signal

- Ink `#171A1C`: type, dark sections and outlines.
- Bone `#F5F3EC`: warm light background.
- Signal `#D9FF58`: primary action and moments of emphasis.
- Muted gray for supporting labels; extra color only for meaningful states.

No default purple gradients, giant glowing orbs, fabricated testimonials, or false savings figures. A single original **clockwork bot** is the recurring mascot, paired with purposeful schematic graphics and live product UI. Official AI platform logos may be integrated later using licensed sources and correct product guidelines, but the initial interface uses text labels and neutral symbols.

## Interaction principles

1. Useful in under 30 seconds, no registration.
2. Tap first, drag-and-drop as a progressive enhancement.
3. Selected role and tasks always produce an intelligible preview.
4. Download a real pack, not a fake button.
5. Honest scope and test labels.
6. Fast on mobile; reduced-motion supported.
7. Keyboard accessible, semantic HTML, visible focus states.

**Fictional inspiration is aesthetic, not a claim of AI consciousness or unrestricted autonomy.**
