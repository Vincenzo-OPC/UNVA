# Roadmap

## Now: accessible, usable first release
- [x] Public MIT-licensed repository and project README.
- [x] Mobile-first product website with a restrained visual identity.
- [x] Interactive multi-task selector and platform picker.
- [x] Local ZIP setup export: SKILL.md, setup guide, manifest, synthetic test cases.
- [x] Basic deterministic tests and CI configuration.
- [ ] Confirm GitHub Actions pass in the user's repository.
- [ ] Enable GitHub Pages deployment in repository settings (not automatically configured).
- [ ] Run an independent accessibility review on real mobile devices.

## Next: validate agents, not just instructions
- [ ] Consent-based Grok Bot test, save a successful workflow as a native skill/template and publish evidence.
- [ ] Hermes Agent install/test in isolated environment.
- [ ] Check documented support/availability for dots and Claude Duet in relevant regions.
- [ ] Add meaningful human-vs-automation quality/time measurement protocol.
- [ ] Recruit three independent contributors for recipe and setup QA.

## Later: movement and scaled adoption
- [ ] GitHub issue templates, discussions and community showcase.
- [ ] Reviewed recipes across VA and BPO functions, no favored industry.
- [ ] Optional skill registry / platform-specific automation packaging if demand is demonstrated.
- [ ] Real-case audited outcomes, anonymized and consent-based.

**Non-goals now:** new foundation model, proprietary bot runtime, unattended business account automation, fake cost calculators, unverified job elimination claims.
